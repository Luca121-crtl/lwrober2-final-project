Helping Students Find Greystar-Managed Apartments

Greystar Living Hub is a simple starting point for students who want clean, reliable off-campus housing near campus. This project site brings example communities, key details, and basic renting info into one place so the process feels less overwhelming.

This is a class project, not an official Greystar site, but it is designed to look and feel like a small housing hub that a student could actually use.
