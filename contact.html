Contact the Project Creator

This page represents how a real housing hub might collect questions from students. For this class project, the form does not send data anywhere, but it demonstrates how a basic contact experience could look.

If this were a live site, students could use this form to ask about availability, tour times, or how to start an application at a Greystar-managed community. For project questions, you can reach the creator directly at lwrober2@asu.edu.
